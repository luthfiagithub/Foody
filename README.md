# Foody
**Foody** adalah aplikasi mobile untuk memesan makanan dengan mudah dan cepat. Saat ini repo ini berisi **UI Prototype** yang dirancang menggunakan Figma, sebagai langkah awal pengembangan aplikasi.

---

## Prototype 
🔗 https://www.figma.com/design/PtUbhdJ2gTFG89z7aoYAXO/Foody?node-id=0-1&t=mX1FcweShqBcs8iL-0

## Fitur (UI Prototype)  
- **Homepage**: Menampilkan kategori dan rekomendasi makanan.
- **Search**: Cari makanan favorit dengan mudah.
- **Cart**: Tambahkan makanan ke keranjang.
- **Checkout**: Proses pemesanan dan pembayaran.
- **Favorites**: Simpan menu favorit.
- **Profile**: Halaman profil pengguna.

## Tech Stack (Planned)  
- **Frontend (UI)**: Kotlin *(planned)*  
- **Backend**: Node.js + Express *(planned)*  
- **Database**: PostgreSQL (Main Database), Room Database (local storage), DataStore (for small key-value data like token, preferences), *(planned)*
